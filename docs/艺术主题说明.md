# 构成主义与瑞士风格主题

两套主题均已在设置注册，保留默认主题与磁带未来主题。每套都有独立浅色、深色配色，切换即时保存；重启后恢复风格和明暗模式。

0.1.4 起接入真实控件样式：构成主义采用直角、2–2.5 像素粗描边和朱红实色操作块；瑞士风格采用 2 像素微圆角与 1 像素细线。卡片、输入框、按钮、筛选片的边缘一起适配。每个操作按钮有独立 CSS 类，可覆盖形态；页面组织、课程色标与功能入口保持简洁。

接口与完整类表见 `前端UI与CSS主题约束.md`、`按钮样式类清单.md`。

| 主题 | 浅色方向 | 深色方向 | CSS |
| --- | --- | --- | --- |
| 构成主义 | 暖纸、朱红、炭黑，少量柔和金色容器 | 暖炭黑、米白文字、明亮朱红与琥珀状态 | `assets/styles/constructivist.css` |
| 瑞士风格 | 冷白、石墨文字、克制红色与冷灰层次 | 近黑、冷灰表面、清晰白字与柔和红色强调 | `assets/styles/swiss.css` |

设置中的缩略图直接读取对应主题 CSS，浅深模式改变时一同更新。新主题沿用统一 Flutter 组件，不启用磁带主题的颗粒与网格效果。

## 开发接入

- `PilotStyle` 新增 `constructivist` 与 `swiss`，CSS 文件与 style-id 对应；旧偏好 ID 保持兼容。
- 主题目录已通过 `assets/styles/` 注册，不需要额外图片、字体或插件。
- 主题缩略图改为读取 CSS 的 paper/stage/accent/line，不再使用旧主题硬编码预览色。
- `test/style_test.dart` 扩展为四套主题 × 两种明暗 × 四类尺寸/字体规格；补充关键对比度、新主题偏好恢复、设置路由保持检查。
- 启用 `UI_PREVIEWS=true` 可生成新主题的实际月历、数学对话与设置截图。
