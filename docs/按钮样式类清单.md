# 按钮样式类清单

2026-10-18：51 个显式操作入口的独立语义类。相同功能的循环实例共享类。

0.1.5 起，Agent 顶栏的 chat-history、chat-new、agent-settings 固定无描边，主题中的描边声明不会给它们加框。

默认合并顺序：`.cp-button` → 基础类型类 → 独立操作类。每个入口仍使用原生 Flutter 按钮处理业务与无障碍语义。
详见 [自定义皮肤的类说明文档](自定义皮肤的类说明文档.md)。
