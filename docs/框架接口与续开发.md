更新：2026-10-15。按用户要求，优先完成 Android 页面和数据接口；**MCP、Agent 排程逻辑暂停开发，保留当前实现，默认不启用**。

## 现在可以做什么

- 接下来：查看待办、课程开始/结束倒计时、进行中时间条，按类别和学科筛选。
- 课表：按周导航、按天查看详细开始/结束时间和地点，包括课程、考试、个人固定日程。
- 事项：新增和编辑作业、考试、个人任务、固定日程，勾选完成；预计用时由用户填写。
- Agent 页面：新建、切换、重命名、删除本地持久化会话；消息和方案展示组件已保留。发送和方案确认按钮当前禁用。
- 设置：本科生账号、自己的 DeepSeek Key、模型 ID、长期偏好、学校同步状态；复制日程 JSON。
- 学校适配器：沿用原仓库本科教务网、学在浙大、统一认证与校历解析，映射成统一事项。

这是一套 Flutter 客户端 + 本地 Dart 服务层框架，**没有另外搭建云端 REST 服务**。学校接口和 DeepSeek 的 HTTP 客户端在服务层中；前端不需要自行发起这些 HTTP 请求。

## 数据接口契约

`PlannerDataApi` 是页面的数据入口，`PlannerRepository` 是当前实现。列表为只读视图，写入通过异步方法；订阅 `addListener` 更新 UI。存储失败不会发布新的内存状态。

| 接口 | 输入/返回 | 约定 |
|---|---|---|
| `items` / `find(id)` | `List<Item>` / `Item?` | 排序后的事项；未知 ID 返回 null |
| `saveItem(item)` | `Future<void>` | 新建使用唯一 ID；修改调用旧 Item 的 `patch`，版本冲突要求重新编辑 |
| `removeItem(id)` | `Future<void>` | 不允许删除学校来源事项；个人事项可删除 |
| `setPreferences(text)` | `Future<void>` | 明确填写的长期偏好；空字符串表示清空 |
| `sessions` | 会话 JSON 列表 | 本地持久化；每个会话独立 ID |
| `saveSession(session)` | `id/title/messages` | 同 ID 更新，否则新建 |
| `deleteSession(id)` | `Future<void>` | 删除历史与未确认方案，已写入的事项保留 |
| `syncStatus` | 按来源分区的 map | `checkedAt/updatedAt/error`，时间为 UTC ISO8601 |
| `SchoolDataApi.refresh` | `force/interactive` | 合并并发请求；默认15分钟内不重复；force 手动刷新，interactive 允许验证码 |

前台启动、回到 App 与手动刷新触发学校同步，无后台任务。失败保留已有日程，页面显示数据未更新。没有真实本科生账号，所以真实登录、验证码与学校最新响应需要下一次真机联调，不能把解析测试视作已验证线上可用。

### Item JSON

```json
{
  "id": "unique-id",
  "categoryId": "homework",
  "title": "线性代数第三次作业",
  "subject": "线性代数",
  "notes": "完成第1至5题",
  "location": "",
  "origin": "manual",
  "sourceKey": "",
  "start": null,
  "end": null,
  "deadline": "2026-10-20T15:59:00.000Z",
  "completed": false,
  "estimatedMinutes": 60,
  "parentId": null,
  "revision": 0
}
```

- `categoryId` 为稳定字符串：`course/homework/exam/task/event`；以后增加类别无需修改旧 JSON 的整数枚举。
- `start/end` 同时存在表示占用时间；`deadline` 是截止时间节点。考试可以有时间段，也可以只有截止节点。
- `estimatedMinutes = null` 表示用户尚未填写；禁止视为零或由模型猜测。
- `origin` 为 `school/manual/agent`。`sourceKey` 对应同步分区；`parentId` 为未来排程时间块关联的任务。
- 写入 UTC ISO8601；界面显示设备本地时间。学校校历解析遵循原实现；非中国时区设备的学校时间解释仍需真机专项验证。
- 学校重同步保留本地填写的完成状态、用时和备注。

### 会话 JSON

```json
{
  "id": "session-id",
  "title": "本周复习安排",
  "messages": [
    {"role": "user", "content": "先帮我看这周的任务"},
    {"role": "assistant", "content": "待接入模型"}
  ]
}
```

`draft` 和 `applied` 字段已经预留给方案展示。当前会话随账号快照保存，尚未实现大规模历史的分页/惰性加载；后续若消息量变大，应拆独立会话存储，保持此接口稳定。

## 构建与交付边界

推荐 Flutter 3.38.1 / Dart 3.10 / JDK 17。Android minSdk 28，Gradle 8.13。

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

首次缺少 Gradle wrapper 时，可用本机 Gradle 执行 `gradle -p android wrapper --gradle-version 8.13`，CI 已包含此步骤。手动触发 Build Android development APK 会产出 debug 签名测试包；正式发布签名仍需单独配置。

没有把临时 DeepSeek Key 写入代码或文档。本机安全存储保存用户自己的 Key 和学校凭据。新快照不会读取或破坏原版 Hive 数据，也未实现原版数据自动迁移。

重构前备份：仓库旁 `../backups/celechron-before-android-lite.tar.gz`。暂停代码与测试均保留在当前目录，后续可以直接续接，不必重做页面。
