# 自定义皮肤的类说明文档

适用：ChronoPilot-Go 0.1.4，2026-10-18。

## 给用户的入口

1. 打开设置，选择预设主题与浅色 / 深色。
2. 点击“编辑自定义皮肤 CSS”，可粘贴由其他 Agent 编写的皮肤。
3. 从默认模板开始时，自动使用 `--style-id: custom;`。
4. 修改后点击“保存并应用”；失败会显示原因，当前皮肤不变。
5. 点击“复制 CSS”可将当前文本交给外部编辑器，修改后再粘贴回来。
6. “载入默认模板”只改编辑框文本；确认保存后才改变已保存皮肤。
7. 可随时切回默认、磁带未来、构成主义或瑞士主题；自定义文本仍保留。

当前提供一个用户自定义槽位。额外内置主题有三套；若要同时保留多份个人皮肤，先在外部保存不同 CSS 文本并按需替换槽位，暂未实现多文件管理器。

## 给艺术风格 Agent 的要求

请以 [default_style.css](../assets/styles/default_style.css) 为基础，保留所有浅深色根变量；交给 App 内编辑器的版本把 `--style-id` 改成 `custom`。可直接复制 [theme.template.css](templates/theme.template.css)。

这不是网页，不能用浏览器 CSS 随意改布局。支持的接口与禁止事项以 [前端 UI 与 CSS 主题约束](前端UI与CSS主题约束.md) 为准。完整入口名见 [按钮样式类清单](按钮样式类清单.md)。

## 一个操作对应一个类

例如发送按钮是 `.cp-agent-send`；保存事项是 `.cp-item-save`；学校刷新是 `.cp-school-refresh`；删除事项是 `.cp-item-delete`。无需新增 Dart 子类或复制按钮实现，每个实际操作使用自己的样式类，通过 `PilotControl` 接入原生控件。

```css
.cp-button { --radius: 0; --border-width: 2; --border-color: ink; }
.cp-icon-button { --border-width: 2.5; }
.cp-agent-send {
  --radius: 0;
  --fill: accent;
  --foreground: on-accent;
  --border-color: ink;
}
.cp-item-delete { --foreground: danger; --border-color: danger; }
.cp-panel { --radius: 0; --border-width: 2.5; --border-color: ink; }
.cp-composer { --radius: 2; --border-width: 2; --border-color: accent; }
```

以上放在完整根块之后。基础类、类型类、操作类依次覆盖；不是通过增大选择器优先级来争夺样式，也不会影响其他按钮类。

- 构成主义：直角、粗线、暖纸 / 炭黑 / 朱红的实色对比。
- 瑞士风格：细线、极小圆角、明确层级与克制的强调色。
- 两种风格共用页面结构，边框和形状可以明显不同。
- 不改点击范围、页面位置、按钮文本、业务行为；不加入海报式装饰。

## 浅深色如何生效

根块同时提供 `paper` 与 `dark-paper` 等色值；组件属性使用 ink、accent、surface 等语义名称。切换明暗时会读取对应颜色，不需要媒体查询。

`on-accent` 用于强调色上的文字：浅色通常白字，深色通常深字。不要在浅红底上强行使用浅色文字。

## 新增操作的接入方法

1. 用唯一小写连字符名称包裹原生按钮：`PilotControl(className: 'my-action', kind: 'icon-button', child: IconButton(...))`。
2. kind 必须使用已支持类型；不要给主题接入网络或业务状态管理。
3. 在 CSS 中新增 `.cp-my-action`；未声明的属性继承类型类。
4. 在类清单中记录入口，并检查浅深色、禁用态、小屏与文字缩放。

AppBar 内使用显式 IconButtonTheme 等组件主题，避免被工具栏局部主题覆盖；悬浮按钮依赖局部 ThemeData。CSS 只在载入 / 保存时解析，不在每帧解析。


## 0.1.5 顶栏图标修正

Agent 顶栏的 `.cp-chat-history`、`.cp-chat-new`、`.cp-agent-settings` 固定使用无描边图标，所有主题和已保存自定义皮肤一致；界面层的 BorderSide.none 优先于类中的描边声明。图标颜色、点击范围与业务行为保留，其他按钮和容器边框不受影响。
