# Android 精简版：已确认的功能与数据设计

## 范围

仅 Android、本科生账号。保留课程、作业、考试、个人任务、固定日程、“接下来”、倒计时、详细时间线和 DeepSeek Agent。移除成绩/GPA、实践记点、校园卡、原贪心自动排程、重复日程编辑、其他平台宿主、通知与后台任务。没有通知权限申请，没有提醒服务。

主导航：今天 / 课表 / 任务 / Agent。今天提供类别和学科过滤。设置管理本科登录、刷新、Agent 密钥和长期偏好。

## 统一事项 Item

使用稳定字符串 categoryId，而不是持久化 enum 下标。类别注册表目前包含 course / homework / exam / task / event，未知类别可回显，新增类别无需更换存储格式。

所有事项共有 id、categoryId、title、subject、notes、location、origin、sourceKey、start、end、deadline、completed、estimatedMinutes、parentId、revision。时间以带时区语义的 UTC ISO 8601 保存；UI 按本地时区展示。学科字段统一标准化空白，供作业过滤和 Agent 使用。

- 课程、固定日程、有具体考试时间的考试：start/end，阻挡排程。
- 作业、个人任务：deadline 可选，estimatedMinutes 只能由用户填写。
- 无具体时段的考试：deadline 为考试节点，可倒计时，但不虚构结束时间。
- Agent 创建的学习时段使用 event，parentId 指向作业或个人任务；完成学习时段不自动完成源任务。
- 所有类别共用倒计时规则：未开始显示距开始，进行中显示距结束和进度，无时段显示距 deadline；无时间明确显示“未设置时间”。

学校刷新只替换对应来源分区，保留完成标记、预计用时和本地备注。失败时保留旧数据，不伪造“更新于”。ID 由来源及稳定业务键生成。删除/完成源任务会清理其尚未开始的 Agent 时段。

## 持久化与并发

Hive 中保存版本化 JSON 快照；用户账号对应独立命名空间。事项修改、学校合并、方案应用均经过串行写队列，成功持久化后通知 UI。旧版本 Hive Box 不删除；新模型不直接读取含旧 TypeAdapter 的旧 Box，旧数据迁移不在首版自动进行（重新登录获取学校数据，个人数据需另行迁移）。源码重构前备份在父目录 backups。

## Agent

DeepSeek 官方 Chat Completions；API Key 单独保存安全存储。每个账号支持多个可重命名/删除的会话，逐会话懒加载历史，只把最近有限消息发给模型；长期偏好独立保存。

每轮请求注入固定系统指令和最新 JSON 数据区，含当前时间/时区、课程/考试、作业截止日期、完成状态、用户填写的预计用时、已有安排和数据更新时间。文本字段视为数据，不能覆盖系统指令。可查看、复制上下文 JSON。模型无法写文件或执行任意命令。

未知预计用时的任务不能被模型分配学习时段，Agent 应提示用户到任务表补充。方案以 JSON 工具返回新增/调整/删除操作；本地校验冲突、截止时间、来源、工作量、旧版本；预览后一次确认写入。调整已有安排也要预览，不直接执行。已有草案在数据或会话变化后不自动套用。

## 更新与性能

缓存优先。启动/恢复前台时检查缓存时效，超过15分钟异步刷新；手动刷新可强制更新；同一时刻只执行一次同步。仅请求当前学年及临近下一学年的本科课表、考试和作业，不抓取历史成绩。学校各模块独立失败降级。

按数据变更建立排序后的事项列表；倒计时只在可见页面的小组件内使用秒级 Timer，不每秒写库或重算课程。后台不轮询、不推送。

## 验证

覆盖分类扩展、日期/时区、倒计时、截止日期、预计用时缺失、冲突、方案幂等、数据版本变化、学校刷新保留用户字段、多会话隔离与持久化。真实学校接口需要本科账号真机验证；不得将离线测试说成线上验证。
