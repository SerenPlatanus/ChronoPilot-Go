# 界面与主题开发说明

2026-10-16。本轮以备份原版的简洁日历、课程色标、圆角日程卡片与分组设置为结构参考。默认主题与磁带未来主题使用同一套组件和排版，只改变配色、背景质感；各自可选浅色或深色，设置自动保存。

## 页面与操作

- 接下来：即将开始、今日占用时间条、按倒计时目标排序的后续事项。倒计时每秒刷新，退后台暂停计时器；没有通知。
- 课表：默认展开整月，日期下方用课程颜色圆点标记；可收起为一周、翻月/周、回今天。点日期查看当天课程、固定安排和作业截止节点。
- 大课表：月历右上角入口，默认七列同屏，显示真实日期上的时段。支持前后周、今天、放大后横向滚动；全天时段可纵向滚动，首次定位早晨。同日冲突事项并列，短时段只显示可容纳的文字，点击查看完整详情。当前时间线每分钟更新。
- 事项：沿用作业、考试、个人任务、固定日程，完成勾选、用户填写预计用时、编辑删除功能。
- 筛选：顶栏漏斗按钮展开类别与学科选项；筛选也适用于接下来的倒计时列表。
- 学期：课表和事项顶部按学年半学期切换，例如 `26-27秋冬`、`25-26春夏`；另有全部学期，以及存在未定日期学校事项时的“未归属学期”。课程优先使用同步分区 `courses:学年起始年:1或2`，避免仅凭学科名称混合历史记录。个人手动任务保持可见。
- Agent：保留多会话、方案预览、确认写入、对话调整。回复使用 Markdown 渲染，支持标题、粗体、列表、引用、行内代码、代码块和表格；文字可选择，消息右下角可复制原文。链接可查看并复制；图片显示替代文字，不自动请求外部资源。
- 设置：按外观、账号、DeepSeek、偏好、同步状态、MCP 分组，保留全部已实现入口。

## 实现边界

学期选择展示已经同步或缓存的数据，不会凭空生成历史课程。本轮未扩大历史年份同步范围。作业/考试缺少学校学期分区时，暂以开始时间或截止日期作学期筛选参考；无日期学校事项单独归入未归属学期。若后续学校接口提供明确学期 ID，应优先保存该字段，替换日期回退规则。学年在九月切换；春夏属于前一年开始的学年。界面不推测校历周次。

CSS 的 `:root` 自定义变量由 Flutter 读取；普通 CSS 选择器是对应的参考样式，不会直接变成 WebView。组件结构应在 Dart 中修改，主题文件仅维护颜色与共同视觉参数，避免因主题不同产生两套页面。

## Agent 公式、历史侧栏与图标更新

- 聊天页面只保留一层顶栏：左侧历史对话，居中当前标题，右侧新会话与设置；取消会话下拉框、重复标题和介绍面板。AI 回复直接排版，用户消息使用简洁气泡。
- 历史侧栏支持左边缘滑出、纵向滚动、点选切换、重命名与删除。新会话记录 `createdAt`，每轮消息写入时更新 `updatedAt`，按今天/昨天/最近七天/更早分组；旧记录没有时间时标记历史会话，不伪造日期。会话行按需构建。
- 切换会话保留当前页面生命周期内未发送的输入；发送后的消息继续持久化到原仓库，确认写入日程的机制不变。
- 数学公式支持 `$…$`、`\(…\)`、`$$…$$`、`\[…\]`，使用 `flutter_math_fork` 进行原生 Flutter 排版。Markdown 代码块/行内代码保留原文；公式错误回退原文，宽公式横向滚动。复制整条消息保留原始 Markdown/TeX。
- `lib/ui/math_markdown.dart`：Markdown 数学语法扩展与公式构建器。
- `lib/planner/session_drawer.dart`：历史会话分组与侧栏列表。
- `lib/ui/eclipse_mark.dart`：聊天空白页的 SVG 日食标志。
- `assets/branding/eclipse.svg`：可编辑图标源文件；`eclipse.png` 是预览。Android 各密度 PNG 及 API26 自适应前景均已替换。灰底、黑色右月面与亮白左月牙。
- 独立包名仍为 `app.chronopilot.go`，继续使用 ARM64 Release 构建，避免与原版 Celechron 覆盖。

## 图标安全留白与流式回复

- 桌面图标：自适应前景四边各增加 14dp 留白（108dp 图层中的主体线性缩小约 26%），避免定制启动器的蒙版裁掉月面与指针；旧式启动器的各密度 PNG 也同步留白。聊天页图标保持原尺寸。布局预览为 `docs/ui-previews/launcher-safe-area.png`，实际启动器蒙版仍需手机确认。
- `DeepSeekClient` 改用官方 Chat Completions SSE（`stream: true`）。按 UTF-8 字节流、行、SSE 事件顺序解码，忽略保活注释；按工具调用 index 拼接函数名与 JSON 参数，只有完整结束才返回可执行的工具调用。保留响应体上限、超时、安全错误及取消。
- `AgentStreamingClient` 是可选扩展接口，原有非流式测试客户端仍可使用；正式 DeepSeek 客户端始终走流式。
- `PlannerChat.streamedText` 只保存当前请求的临时文本，界面最多约每 50ms 更新一次；完成后才持久化一条正式回复。取消、断流、截断或缺少结束标志时清除临时内容，不把半截回复或方案记入历史，重试保留原用户消息。
- 聊天页在当前会话显示增量回复；切换其他会话不会串入该内容。用户已向上滚动阅读时，不强制跟随新文字滚到底部。工具方案仍需用户确认后写入。
- `test/agent_stream_test.dart` 覆盖中文跨字节、多工具交错参数、断流/截断、请求完成前的界面更新、取消与重试；`test/deepseek_client_test.dart` 用本地 HTTP SSE 服务验证请求携带流式标志，并在服务端结束响应前收到首段。
- 完整回归 102 项通过；未使用真实 DeepSeek Key 进行付费联调。

接口格式参考：[DeepSeek Chat Completions 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)。
